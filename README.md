# mi-primera-tienda-web
# Interactive Web Store

A responsive storefront built with vanilla HTML, CSS, and JavaScript.

## Features

- Interactive shopping cart with persistent state using `localStorage`
- Custom SVG product illustrations with dynamic colors
- WhatsApp links for order requests and customer contact
- Google Maps location link
- Typography using Google Fonts: Bodoni Moda and DM Sans

## Technologies

- HTML5
- CSS3
- JavaScript
- SVG
- Browser localStorage

## Project status

Personal portfolio project.

## Notes

This project uses external Google Fonts and links to WhatsApp and Google Maps. It does not include a payment processing system or a server-side backend.
